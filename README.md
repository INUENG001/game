# เส้นทางเศรษฐี (Road to Millionaire)

ต้นแบบเกม Java Swing ใช้ภาพประกอบจากโฟลเดอร์ `image` และไม่ต้องติดตั้งไลบรารีเพิ่ม

## วิธีเปิดเกม

ใช้ Windows ที่ติดตั้ง JDK 17 ขึ้นไป แล้วดับเบิลคลิก `run_game.bat` หรือเปิด PowerShell ในโฟลเดอร์นี้และรัน:

```powershell
.\run_game.bat
```

## วิธีเล่น

- เริ่มต้นด้วยเงิน 0 บาทและหนี้ 20,000,000 บาท
- แสดง Living Statue บนแท่นกลางฉาก แล้วกด `Space` หรือปุ่ม **ค้างท่า!** เมื่อเข็มอยู่ในแถบสีทอง
- เล่นทั้งหมด 5 รอบ แต่ละรอบเปลี่ยนท่ารูปปั้นเมื่อกดถูกหรือพลาด; กดถูกได้ทิป 10 หรือ 20 บาท
- ซื้อสลากระดับ 1, 2 หรือ 3 เมื่อมีเงินพอ
- ราคาสลากระดับ 1 / 2 / 3 คือ 100 / 1,000 / 5,000 บาท; รางวัลใหญ่จ่าย 15× / 20× / 30× ของราคาสลาก
- สลากพิเศษใช้เงินทั้งหมดที่ถืออยู่ โอกาสชนะคำนวณจากเงินที่ถือและจำกัดสูงสุด 50%
- เมื่อถูกรางวัลพิเศษ เกมจะชำระหนี้และจบด้วยหน้าชนะ

## โครงสร้างคลาส

- `GamePanel` วาดหน้าจอและรับอินพุตของผู้เล่น
- `GameController` จัดการการเปลี่ยนหน้าจอและลำดับการเล่น
- `GameModel` เก็บยอดเงิน หนี้ และสถิติ
- `LotterySystem` สุ่มผลสลากและคำนวณโอกาสของสลากพิเศษ
- `LivingStatueSession` จัดการจังหวะและทิปของมินิเกม
- `AssetManager` โหลดภาพจาก `image`
- `GameWindow` และ `Main` สร้างหน้าต่างเกมและเริ่มโปรแกรม
